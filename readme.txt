Adds an egaline material calculator to WooCommerce product pages with calculated cart item pricing and order metadata.

== Description ==

WooCommerce Egaline Calculator adds product-specific calculator fields for thickness, area, required kilograms and bag count. The plugin stores calculator metadata in cart and order items and lets WooCommerce calculate cart totals, tax, coupons, fees, shipping and payment totals.

== Installation ==

1. Upload the plugin folder to /wp-content/plugins/.
2. Activate WooCommerce.
3. Activate WooCommerce Egaline Calculator.
4. Configure calculator settings on individual WooCommerce products.
